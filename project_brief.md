# My agent: Histogeo Tutor

One-liner: A conversational learning agent that helps students master history and geography through concise event summaries, terrain visualizers, and personalized study tracking.

Tool coverage:
- Memory: Student's study history, previously explored eras/topics, weak areas, and exam revision progress across sessions.
- Tools: Historical event lookup (search/grounding), geographical terrain fetcher (river systems, hills, climate), and study activity logger.
- Catalog/UI: Historical event summary cards, timeline display cards, geographical terrain profile cards, and revision progress tables rendered via A2UI.
- Image gen: Illustrative scenes of historical incidents (e.g., Maurya Empire architecture, Battle of Panipat) and realistic landscape illustrations showing regional terrain (river basins, hill ranges).
- Sandbox: Quiz score calculations, study progress metrics, and timeline interval computations.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Google Maps API for geographic coordinates, Cloud Trace for tracing tool calls.
